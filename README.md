## 📌 Overview

The **SOIC Knowledge Vault** is a high-speed, auditable, and searchable knowledge engine designed around the **SOIC TVGP Investing Framework** (**T**heme, **V**aluation, **G**rowth, **P**romoter). 

It converts over 38 intensive lecture recordings across 5 subcourses into structured, citable documentation with **sub-second search**, **interactive synchronized audio transcripts**, **automated investment rule harvesting**, and **automated quality-assurance verification queues**.

It operates with zero server sleep, zero cold-starts, and feeds decision rules directly into the **[Sanchay Portfolio Tracker](https://portfolio-tracker-frontend-iota.vercel.app)**.

## 🎯 Core Features

### 1. 3-Tier Hierarchical Knowledge Drill-Down
Content is organized across three standardized depth layers:
* **Level D3: Sub-Course Overview (`*_SubCourse_Summary.md`)**  
  High-level curricular map, core pillars, progression flowcharts, and lecture index.
* **Level D2: 3-Minute Summary Reference Cards (`*_Summary_References.md`)**  
  Rapid revision cards for each lecture: core thesis, framework highlights, decision thresholds, and key company case studies.
* **Level D1: Detailed Lecture Reports (`*_LecXX_Report.md`)**  
  Comprehensive deep-dive reports with worked examples, conference call breakdowns, forensic red flags, formulas, glossaries, self-tests, and audio timestamps.

### 2. 🎙️ Synchronized Audio Transcripts & Deep-Linking
* Every timestamp citation in reports (e.g., `[00:14:22]`) is an interactive hyperlink. Clicking it instantly opens the interactive player at that exact second.
* **`<TranscriptViewer />` Component**: Features interactive paragraph cue jumping, synchronized karaoke text highlighting, playback speed controls, and keyword search.

### 3. 🛡️ Automated Verification Queue (Quality Assurance)
* Automated scanner (`scripts/sync.js`) parses all markdown documents for `[? verify]`, `[?]`, or `[? Hindi unclear]` flags left during AI transcript processing.
* Aggregates them into a centralized dashboard ([verification-queue/index.md](verification-queue/index.md)) with direct audio links for fast manual auditing.

### 4. 📊 Automated Sanchay Rules Harvesting
* Scans all markdown comparison tables across lectures for quantitative benchmarks, metrics, and thresholds.
* Compiles them into a structured [public/soic_rules.json](public/soic_rules.json) to power automated pre-flight checks and stock audit scorecards in the Sanchay app.

### 5. 📐 LaTeX Financial & Mathematical Formulas
* Full mathematical typesetting via MathJax 3.
* Renders Dupont ROCE breakdowns, capital turnover equations, and valuation multiples.

## 🚀 Getting Started

### Prerequisites

* **Node.js**: v18.0.0 or later (LTS recommended)
* **npm**: v9.0.0 or later
* **Python**: 3.9+ *(optional, required only for running `normalize_courses.py`)*

### 1. Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/soic-knowledge-vault/soic-knowledge-vault.git
cd soic-knowledge-vault
npm install
```

---

## 💻 Running the App

### Start Local Development Server (Live Preview)

Run either of the following commands:

```bash
npm run dev
```
*or*
```bash
npm run docs:dev
```

* The development server will start with hot-reloading at **`http://localhost:5173`**.
* Edits to Markdown files will update immediately in the browser.

---

### Build Static Production Site

To build the static HTML site for production deployment:

```bash
npm run build
```

This automated command executes:
1. `npm run sync` (normalizes transcripts, injects deep links, updates sidebars & harvests rules).
2. `vitepress build` (compiles all Markdown into optimized static HTML/CSS/JS in `.vitepress/dist`).

---

### Preview Production Build Locally

To test the compiled production site before deploying:

```bash
npm run docs:preview
```

---

### Run Synchronization Pipeline Only

If you added new lectures, updated raw transcripts, or edited Markdown tables, run the sync pipeline:

```bash
npm run sync
```

Individual pipeline tools can also be triggered:
* **Parse transcripts only:** `npm run parse:transcripts`
* **Inject audio timestamp deep links only:** `npm run linkify`

## 📝 Guide: Adding a New Course or Lecture

To maintain full compatibility with the automated pipeline, follow the **Flat Standard Format**:

### Adding a New Subcourse (e.g. `ta` for Technical Analysis)

1. Create a folder under `courses/<code-name>/` (e.g. `courses/ta/`).
2. Add the master summary: `courses/ta/TA_SubCourse_Summary.md`.
3. Add the reference cards: `courses/ta/TA_Summary_References.md`.
4. Add lecture reports: `courses/ta/TA_Lec01_Report.md`, etc.
5. In [scripts/sync.js](scripts/sync.js), register the course code in `courseNames`.
6. In [.vitepress/config.mjs](.vitepress/config.mjs), add the route to `themeConfig.nav`.
7. Run `npm run sync` $\to$ the landing page, dynamic sidebar, rules, and verification queues will auto-generate!

### LaTeX Math Formatting Rules
* To display mathematical formulas, use standard LaTeX enclosed in `$...$` or `$$...$$`.
* **Important:** If your prose mentions literal currency amounts (e.g., `$100 per kg` or `$1 Billion`), escape the dollar sign with a backslash: `\$100 per kg` or `\$1 Billion`, or place it inside backticks: `` `$100 per kg` ``. This ensures MathJax does not mistake currency figures for LaTeX equations.
* When using `₹` inside LaTeX equations, wrap it as `\text{₹}` (e.g., `$$\text{Gross Block} = \text{₹}2,000\text{ crore}$$`).

## 🔗 Integration with Sanchay App

The Vault is designed to integrate seamlessly with the **Sanchay Portfolio Tracker**:
1. **Rule Ingestion**: Sanchay consumes `public/soic_rules.json` to power pre-flight investment checks before a buy order is committed.
2. **Deep Links**: Sanchay's Stock Inspector cards feature citation badges that link directly to the corresponding lecture in the Vault (e.g., `https://soic-vault.vercel.app/courses/cc/CC_Lec04_Report#stage-3`).
